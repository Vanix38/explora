Extensions

Sur le Chrome Web Store, le bouton « Ajouter à Chrome » installe l'extension dans Explora (une confirmation s'affiche avec ses autorisations). Ses boutons apparaissent à droite de la barre d'adresse. Les extensions sont mises à jour automatiquement au lancement puis toutes les 5 heures.

Ce qui marche, et ce qui ne marche pas

Explora est construit sur Electron, pas sur Chrome : le moteur de rendu est le même, mais une bonne partie des API d'extensions de Chrome n'existe pas ou n'est qu'imitée.

  • Fonctionnent en général : les extensions qui modifient l'apparence ou le contenu des pages (scripts de contenu, CSS) et ont un bouton avec un popup. Testée : Dark Reader.
  • En partie : celles qui utilisent le clic droit, les onglets, les cookies, les notifications ou les raccourcis clavier ; certaines fonctions peuvent manquer ou planter. À essayer au cas par cas.
  • Ne fonctionnent pas :
    • les bloqueurs de publicité récents (uBlock Origin Lite, AdGuard, AdBlock…) : ils reposent sur declarativeNetRequest, qu'Electron ne gère pas. Testé avec uBlock Origin Lite : il s'installe mais ne bloque rien. Utilise plutôt le bloqueur intégré (bouclier à droite de la barre d'adresse, réglages dans Réglages) ;
    • la connexion avec un compte Google (chrome.identity), l'historique et les favoris de Chrome (chrome.history, chrome.bookmarks), les téléchargements, les captures d'onglet, le remplacement de la page Nouvel onglet ;
    • les anciennes extensions Manifest V2, refusées à l'installation.
  • Navigation privée : aucune extension n'y est chargée.
